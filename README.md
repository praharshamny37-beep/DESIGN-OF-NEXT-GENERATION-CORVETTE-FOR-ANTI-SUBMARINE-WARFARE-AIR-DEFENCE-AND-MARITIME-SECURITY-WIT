## Project Work

The project documentation and supporting files cover the design study of a next-generation corvette. The repository includes chapter materials and associated figures, with technical hull-form and drawing-related resources organized in the relevant folders.

The hull-geometry material includes the use of the NPL Series as a basis for parent-hull selection and offset development, preparation of hull lines-plan drawings, three-dimensional hull modelling, and hydrostatic-related results, as documented in the project files.

## Software and Tools

The project files indicate the use of the following tools and file formats:

- **LaTeX** — report preparation and compilation.
- **AutoCAD** — engineering drawings (DWG and plotted PDF files).
- **Rhinoceros (Rhino)** — 3D hull modelling (3DM and IGES files).
- **Maxsurf** — hull modelling and hydrostatic-related work (MSD and output files).
- **Microsoft Excel** — calculation and offset workbooks (XLSX files).
- **Python** — dimensions/code-related material.
